OctaFuse Gateway v2.21.0 让更多 MCP 客户端能直接接入：Gateway 的 OAuth 授权服务器支持机密客户端、手工签发凭据和更多客户端预设，发现地址与本机回调也补齐了兼容。供应商可以配置按协议分组的默认请求头和请求体，路由再单独覆盖。路由编辑器能直接从供应商拉取上游模型清单供选择，供应商和模型导入目录改为默认从官网加载，并支持按厂商筛选。管理后台新增登录失败锁定，路由配置界面整体重做，调试台和模拟器能查看上游实际请求。目录补上 Gemini 4 Neon、GPT-6.2 Astra / Sol、Hy4 flash 和 Qwen4 Max 正式版。本版有两条必须先执行的新增迁移 0037 和 0038，只新增可空列或带默认值的列，默认不改变现有行为。

### Proxy

- **MCP OAuth 机密客户端**：动态注册支持机密客户端，注册时返回一次性可见的 `client_secret`。令牌与撤销端点支持 `client_secret_basic` 和 `client_secret_post`，机密客户端可省略 PKCE。需要用 HTTPS 元数据文档标识客户端（CIMD）时，可在 OAuth 卡片中开启，或设置 `MCP_OAUTH_CIMD_ENABLED=true`，默认关闭。
- **MCP 客户端兼容性**：新增授权服务器发现地址 `/.well-known/oauth-authorization-server/mcp[/{slug}]` 和 `/mcp/.well-known/oauth-authorization-server`，资源元数据也可从 `/mcp/.well-known/oauth-protected-resource` 获取。`/mcp` 的 401 响应声明 `scope="mcp"`。本机 `localhost` 回调与 `127.0.0.1` 一样支持动态端口。注册被拒时可搜索 `registration rejected` 日志排查应用规则。
- **供应商默认请求参数**：可按上游协议设置默认请求头和请求体，路由可单独覆盖，路由配置优先。受保护的请求头及 `model` 字段仍由网关管理。原生透传与 WebSocket 入口也会应用配置的请求头。
- **Gemini 签名错误重试**：上游返回 `Corrupted thought signature` 时，网关会清理会话历史中的思考签名，并向同一上游重试一次。

### Admin

- **供应商模型候选**：路由编辑器点击“供应商模型名称”时，按所选供应商加载上游模型列表；已选供应商再次点击也可打开候选。下拉框内可按模型 ID 或展示名搜索本次取回、符合当前路由操作的全部候选；搜索文字不写入路由，长列表使用虚拟滚动。仍可直接输入任意 ID，或在请求失败后手工重试；无可用列表接口或缺少密钥时保持手工输入。刷新结果不落库，出站请求限定官方主机并限制响应大小、分页及耗时，服务端最多返回 1000 条候选。候选只辅助填写，不代表账号有调用权限。
- **供应商和模型导入目录**：导入弹窗默认从官网目录加载，完整目录在缓存刷新后可见更新。模型导入新增「模型厂商」筛选，可与功能分类、搜索和生命周期筛选组合使用，每次按厂商查询都会请求该厂商的目录接口。供应商导入改用模板英文名作为稳定键，避免远端目录顺序变化导致误导入；携带旧下标的请求返回 `409`，重新加载目录后再选择即可。
- **管理后台登录失败锁定**：同一来源或全局管理员账户在 30 分钟内连续 5 次登录失败后，新登录请求冷却 30 分钟；锁定响应提供剩余时间，登录页显示倒计时。计数只保存在管理后台进程内，进程重启后清空；现有会话、管理 API Key 和代理服务不受影响。
- **Provider 自定义参数**：Provider 编辑弹窗新增「自定义参数」页签，可按协议配置默认请求头 / 请求体；调试台预览与线上请求使用同一套合并逻辑。
- **供应商列表与卡片**：宽屏下在供应商名称右侧新增「启用状态」列，并排显示滑动开关和「已启用 / 已停用」文字。卡片压紧协议区，用启用数与总数展示关联路由，将密钥状态和操作分居页脚两侧，并突出待填密钥和无密钥状态。
- **路由筛选与切换**：「总览 / 按模型」模式切换位于「路由配置」工具栏首行右侧。宽屏直接展示卡片或列表、布局模式、倍率和入口路径选项，窄屏统一收入「显示设置」。模型和供应商支持搜索、分组多选及逐项移除，筛选条件可通过链接分享，旧单选链接仍有效。切换卡片和列表会保留当前请求入口和路由组。当前筛选下有未接线模型时默认展开清单。工具栏移除了模型与路由总数以及「配置可用」汇总，组内仍显示可用数。
- **路由配置**：可复制调用路径和模型 ID，悬停提示说明该 ID 用于发起调用。点击模型名称编辑模型，点击标题旁的加号为当前入口和路由组添加供应商。「按模型」的卡片和列表均可切换紧凑与平铺布局，浏览器会记住选择。平铺同时展开每个模型的全部请求入口、路由组和供应商；默认的紧凑布局左侧按「入口、分组、模型、粘性」排列，右侧展示路由，窄屏上下排列。两种布局共用紧凑样式的供应商卡片，首选与回退层按可用宽度排列，并排时用箭头指向回退层。启停开关位于供应商名称下方，权重、粘性绑定人数和请求参数位于上游模型下方，仅在路由组开启粘性时显示绑定人数。列表中的首选和回退层左侧显示优先级和可用数，点击右侧策略名称即可编辑。供应商停用时，在开关下方标注原因。
- **路由价格**：卡片和列表始终逐行展示全部适用时段，用浅蓝底色和左侧竖线标出当前生效的时段，全时段路由只显示一行。可切换实际倍率与原始倍率，悬停或聚焦倍率可查看计算明细。
- **请求参数与调试**：调试台按线上合并规则预览请求头和请求体，标明配置来自供应商还是路由，发送后展示服务端回传的上游请求。模拟器可对照输入 JSON 与网关请求，查看模型、路由组及鉴权来源。语言模型调用完成后，可按请求 ID 查看脱敏的上游快照和生效配置。
- **OAuth 应用管理**：可为不支持动态注册的客户端手工签发固定凭据、重置密钥或删除客户端。回调规则支持子域通配和末尾 `*` 前缀匹配，具体地址优先。新增 Claude Code、Cursor、VS Code、Gemini CLI 和本地 MCP 客户端预设，并补充 WorkBuddy 回调域名。客户端列表 API 支持按 `registration_method` 筛选，并通过 `has_client_secret` 标明是否配置密钥，详见 [Admin API](docs/developers/api/admin.md)。
- **MCP 目录审核**：同步后可逐项对比工具定义及参数结构的变化，接受、启用或跳过后继续审核下一项。支持批量接受定义变更、批量启用新增条目。批量接受接口为 `POST /api/admin/mcp-servers/:id/items/accept`。

### 目录与供应商

以下输入和输出价格均按每百万 token 计。Gemini 和 GPT 的人民币目录价按美元刊例价 ×7 换算。完整规格、缓存价格及参数限制见官网[模型目录](https://octafuse.dev/zh/catalog/models/)。

- **Gemini 4 Neon**（`gemini-4-neon`）：支持多模态输入，输入、思考与输出共享 1M 窗口，同步输出默认 64K。输入 $3，输出 $15，隐式缓存 $0.15。思考默认 `high`，不支持关闭，传入 `minimal` 或 `thinking_budget` 会返回 400。
- **GPT-6.2 Astra / Sol**（`gpt-6.2-astra`、`gpt-6.2-sol`）：支持 1.05M 上下文、128K 输出。Astra 输入 $8、输出 $40，Sol 输入 $2、输出 $10。输入超过 272K 时，输入与缓存价翻倍，输出价为 1.5 倍。工具调用须使用 Responses API，两款模型均不接受 `reasoning.effort=none`。
- **Hy4 flash**（`hy4-flash`）：支持 1M 上下文、约 64K 输出。国内输入 ¥0.5、输出 ¥2，国际输入 $0.07、输出 $0.281。目录价未计入截至 2026-11-30 的 TokenHub 五折优惠。`hy4-preview` 已标记于 2026-12-07 下线。
- **Qwen4 Max**（`qwen4-max`）：正式版支持 1M 上下文、128K 输出，默认思考档为 `high`。国内输入 ¥10、输出 ¥30，国际输入 $1.5、输出 $4.5。`qwen4-max-preview` 的目录价已与正式版对齐，官方预览期至 2026-11-25。
- **OpenCode**：Zen 和 Go 的导入模板分别使用 `https://opencode.ai/inference` 和 `https://opencode.ai/inference/go`，预填 Chat、Responses、Anthropic Messages 和使用 Bearer 鉴权的 Gemini 生成端点。已有供应商如需切换，须手动更新地址。
- **Modelink**：新增七牛云 AI 海外接入模板（`api.modelink.ai`），预填 OpenAI Chat、Responses、Images 生成与编辑、Anthropic 及 Vertex 兼容的 Gemini 端点。中国大陆继续使用「七牛云 AI」模板（`api.qnaigc.com`）。

以上目录更新不会自动覆盖已导入的模型，也不会自动挂路由。

### 升级说明

- **数据库迁移**：必须应用 **0037**（OAuth 客户端凭据字段）和 **0038**（供应商 `custom_params` 可空列），先于同版本 Proxy 与 Admin 执行；D1、Postgres、MySQL 都有对应迁移，只新增列，已有数据不变。步骤与回退见 [0037 迁移说明](docs/operators/migrations/0037-oauth-client-credentials.md) 和 [0038 迁移说明](docs/operators/migrations/0038-provider-custom-params.md)。
- **配置变更**：新增可选的 `MCP_OAUTH_CIMD_ENABLED`（默认关闭）。Admin 的供应商 / 模型导入目录默认从 `https://octafuse.dev` 加载，新增可选的 `CATALOG_BASE_URL`、`CATALOG_TIMEOUT_MS`、`CATALOG_TTL_MS`，详见 [Docker 部署配置](docs/operators/deployment/docker.md)。
- **兼容性**：Admin 进程需要能出站访问 HTTPS 的目录站点。内网或离线部署升级前，请把 `CATALOG_BASE_URL` 指向可访问的目录镜像，镜像需提供 `/api/catalog/providers`、`/api/catalog/models` 和 `/api/catalog/models-by-vendor/{vendor}`，否则导入弹窗无法加载目录。携带旧下标的供应商导入请求返回 `409`，刷新目录后重新选择。管理后台登录失败达到阈值后会被锁定 30 分钟，自动化脚本若用错误密码重试，会触发锁定。OpenCode 已有供应商的地址不会自动更新。
- **建议操作**：先执行 0037 和 0038，再把 proxy / admin / migrate 三镜像更新到同一版本后滚动重启。升级后抽查 MCP 客户端授权、供应商自定义参数、模型候选下拉和导入弹窗。
